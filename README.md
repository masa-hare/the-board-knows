# the board knows

とある大学のホワイトボードより。毎週ひとつの問いと、付箋で集まった声を載せる静的サイト。

- **公開先**: Vercel（`master` ブランチへの push で自動デプロイ）
- **リポジトリ**: https://github.com/masa-hare/the-board-knows
- **技術**: Next.js (App Router) / TypeScript / React

---

## Claude Code を使わずに更新する方法

このサイトは **GitHub に push するだけで自動デプロイ**されます。
そのため、Claude Code を立ち上げなくても **claude.ai の通常チャット** や **cowork** から更新できます。

### 準備（最初の一回だけ）

1. claude.ai または cowork で、**GitHub コネクタ**を有効にする
   （設定 → コネクタ → GitHub を連携）
2. 連携時に `masa-hare/the-board-knows` リポジトリへのアクセスを許可する

これだけで、チャットから直接ファイルを編集・コミットできるようになります。
`master` にコミットが入ると Vercel が自動でデプロイします（数分で反映）。

### 新しい週を追加するとき（コピペ用プロンプト）

下のテンプレートに付箋の中身を貼り付けて、チャットに送るだけです。

```
masa-hare/the-board-knows リポジトリに新しい週を追加して、master にコミットして。

週番号: Week 6
日本語タイトル: （ボードの問い・日本語）
英語タイトル: （ボードの問い・英語）

付箋（日本語）:
- （付箋の文言を1行ずつ）
...

付箋（英語）:
- （英語の付箋を1行ずつ）
...

手順:
1. lib/data.ts に W6 を追加（型は Note[]、各付箋に t/c/tr/q/qt を付ける）
2. components/Site.tsx で import に W6 を足し、一番新しい週として
   <WrittenBoard> セクションを追加（既存の Week 5 ブロックをコピーして書き換え）
3. ビルドが通ることを確認して master にコミット
```

Claude が上記の構造に沿って編集し、コミットしてくれます。

## データ構造の説明

### 付箋データ … `lib/data.ts`

各週は `Note[]` の配列（`W1`〜`W5`）。1枚の付箋はこの形：

```ts
{
  t:  "付箋に書かれた本文",          // 表に表示される文言
  c:  "ny",                          // 色クラス（下記）。英語の付箋は "ny en" のように en を付ける
  tr: "Translation / 翻訳",          // ホバー時に出る翻訳（日本語付箋→英語、英語付箋→日本語）
  q:  "問いに変換した文章",          // タップすると表示される「問い」
  qt: "問いの翻訳",                  // 問い状態でホバーすると出る翻訳
}
```

**色クラス（`c`）**
| クラス | 色   |
|--------|------|
| `ny`   | 黄   |
| `np`   | ピンク |
| `nb`   | 青   |
| `ng`   | 緑   |
| `no`   | オレンジ |

英語の付箋はフォント調整のため `en` を追加：`"np en"` のように書く。

> 色を1枚ずつ指定しなくても、`Site.tsx` の `<Notes notes={...} scatter />` のように
> `scatter` を付けると自動でバラバラの色に振り分けられます（W1・W2 で使用中）。

### 週セクション … `components/Site.tsx`

各週は `<WrittenBoard>` ブロック。新しい週ほど上（先頭）に置く。
既存ブロックをコピーして週番号・タイトル・`<Notes notes={Wx} />` を書き換えるだけ。

## ローカルで開発する場合（任意）

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # 本番ビルドの確認
```

## プライバシー方針

アクセスログ・Cookie などの情報収集は一切行いません。
大学名・所属・個人を識別できる情報は掲載しません。
